# 💳 Credit Risk Prediction System

## 📌 Overview
This project implements a machine learning-based system to predict the creditworthiness of loan applicants using financial and demographic data. The goal is to assist in identifying high-risk applicants and support data-driven lending decisions.

---

## 🚀 Features
- End-to-end machine learning pipeline
- Data preprocessing and feature engineering
- Model training and evaluation
- Credit risk classification
- Docker-based deployment support

---

## 🛠️ Tech Stack
- Python  
- Pandas, NumPy  
- Scikit-learn  
- SQL  
- Jupyter Notebook  
- Docker  

---

## 📊 Machine Learning Pipeline
1. Data Cleaning and Preprocessing  
2. Feature Engineering  
3. Data Transformation  
4. Model Training (Logistic Regression, Random Forest)  
5. Model Evaluation  
6. Prediction  

---

## 🔍 Key Highlights
- Built a complete pipeline for credit risk prediction  
- Applied feature engineering to improve model performance  
- Compared multiple models to select the best-performing one  
- Designed the system for scalability and reproducibility using Docker
